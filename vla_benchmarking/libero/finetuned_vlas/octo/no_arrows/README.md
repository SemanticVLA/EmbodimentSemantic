# Octo-Base 1.5 matched no-arrow retrain

This profile starts from the pinned official Octo-Base 1.5 pretraining
checkpoint and uses only the canonical no-arrow LIBERO source manifest.  The
training configuration is `MATCHED_TRAIN_CONFIG` in `../config.py`; no
checkpoint is generated by importing this package.

Use `OctoRLDSExample`/`serialize_episode` from `../dataset.py` to produce
native RLDS-compatible steps, preserving source episode/frame IDs and applying
the stored-frame 180° rotation exactly once.
